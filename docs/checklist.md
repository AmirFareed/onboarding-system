# Fintech Onboarding Document Verification Checklist

This is the manual checklist used to validate documents submitted by sub-billers for KPITB onboarding.

---

## ✅ Authority Letter
- [ ] Printed on official **department letterhead**
- [ ] **Focal person name and designation** clearly stated
- [ ] **Signed and officially stamped** by the department
- [ ] Account maintenance details appear at the **top** of the authority letter

## ✅ Account Maintenance Certificate
- [ ] Standard, flawless format
- [ ] **Signed and stamped** by the issuing bank
- [ ] Account Title matches Tripartite + Bilateral agreements
- [ ] Account Number matches Tripartite + Bilateral agreements
- [ ] Branch Name/Number matches agreements

## ✅ Application Form (In-Direct Customer)
- [ ] Organization Name filled in
- [ ] NTN / Registration Number provided (or marked N/A)
- [ ] Country of incorporation stated
- [ ] Account Title matches Account Maintenance Certificate
- [ ] Bank Account Number matches Account Maintenance Certificate
- [ ] Nature of Business checked
- [ ] Organization Type checked
- [ ] Business Classification checked (or "Others" specified)
- [ ] Licenses mentioned (if applicable)
- [ ] **Every page signed and stamped**
- [ ] Proprietor / Directors / Partners details (name + CNIC) completely filled
- [ ] "Declaration of Sub-Member" section signed and stamped
- [ ] **KPITB "Aggregator" section** signed and stamped

## ✅ Tripartite Agreement
- [ ] Three parties listed: 1-Link (Biller), KPITB (Aggregator), Sub-biller (Dept.)
- [ ] **No dates in the first 2 lines** (preamble)
- [ ] Correct **organization name** everywhere (no copy-paste errors)
- [ ] Bank details (Bullet 2, Sub-point 5) match Account Maintenance Certificate
  - [ ] Account Title matches
  - [ ] Branch Name/Number matches
- [ ] All bullet/number points are **complete** (details of documents present)
- [ ] Bilateral account number in Section 6 matches Account Maintenance Certificate
- [ ] Signatures and witnesses from **all 3 parties** (1-Link, KPITB, Sub-biller)

## ✅ Bilateral Agreement (SLA)
- [ ] **PayMin** or **Digital Muhasil** mentioned explicitly
- [ ] Organization name clearly stated
- [ ] Main body text (A, B, C, D, etc.) is intact and unmodified
- [ ] **Dates are empty** (left blank intentionally)
- [ ] **Section 5.2**: Transaction charges mentioned (e.g., "as per prevailing charges of 1-Link in PKR")
- [ ] **Section 6**: Bank account numbers listed and match Account Maintenance Certificate
- [ ] Party A signatures + witnesses present
- [ ] Party B (name, designation) + witnesses present and consistent

## ✅ E-Stamp Papers
- [ ] Visual appearance resembles real e-stamp (brownish texture, not plain white)
- [ ] Non-judicial stamp description is accurate
- [ ] First Party and Second Party details are correct
- [ ] E-stamp watermark and extensions are valid

## ✅ Business Requirement Document (BRD)
- [ ] Lists all revenue-generating services that need to be digitized
- [ ] Services mentioned are relevant and specific

## ✅ Formal Request Letter
- [ ] Subject line: *"Onboarding as a sub-biller with KPITB"* (or similar)
- [ ] Letter explicitly requests KPITB onboarding as sub-biller

## ✅ CNIC Copies
- [ ] CNIC copies of all authorized persons attached
- [ ] CNICs are clearly legible
